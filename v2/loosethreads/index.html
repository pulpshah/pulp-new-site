Three layers, one cloth

Dye, Warp and Weft.

Colors, parts and pages, woven together.

The names come from weaving, and the analogy holds. Read the cloth beside this: wherever a part's thread shows on top, that pattern is made with it.

Dyethe tokens
Every color, size, spacing step, radius, duration, easing curve and font. A part never holds a raw value like a hex code or a pixel count. It asks Dye.
Warpthe parts
Buttons, fields, segmented sliders, meters, sheets and menus. On a loom the warp holds the tension. Each part is mounted from its contract, with every state drawn: rest, hover, press, focus, busy and done.
Weftthe patterns
Panels, rooms and whole screens, woven across the parts. A change to one part travels into every pattern that uses it, on purpose.

01

Install the kit

One package holds Dye, Warp and Weft, with every contract inside it.

pnpm add @loosethreads/kit
02

Pick a mode

Wrap your app once. Light, dark and mono come from the same tokens, and the reader can scrub between them.

import { Dye } from '@loosethreads/kit';

<Dye mode="dark" scrub>
  <App />
</Dye>
03

Mount a part

Parts take an intent. It rides along with every press, already labeled, so you never maintain a tracking plan.

import { Button } from '@loosethreads/kit/warp';

<Button intent="start-free">Start free</Button>

Every part carries its contract. This is a real excerpt of the Button contract, as it sits in the kit today: one slot filled with its source, one not applicable with its reason, and one lead call that says why.

{ "part": "Button", "layer": "warp", "slots": {
  "state.busy": { "value": "saving, saved, offline: does nothing when pressed and says so (aria-busy or aria-disabled)", "src": "LT-BTN-009" },
  "state.invalid": { "na": "a button has no value to be invalid" },
  "meaning.name": { "value": "its visible label; an icon-only button carries an accessible name, shown by its tooltip on hover and focus", "src": "rq-5" },
  "text.tooltip": { "value": "an icon-only button hands the label it is given to its tooltip, so the tooltip and the accessible name always match", "by": "lead", "src": "lead: v2.2 IconButton passed nothing to its tooltip; one label for both closes that gap" }
} }
04

Turn on X-ray

Press Alt and X on any page running the kit, this one included. Every part is sewn round with a running stitch and a tag naming its contract and who decided it. Press again to put the paint back.

05

Ask it why

lt why is blame for pixels. Point it at any slot and it tells you the value, who decided it, when, what it replaced and where it is proven.

$ lt why button.radius

Press Run to ask.
